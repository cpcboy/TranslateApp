## 快捷键第三次调整 → ⌃⌥⌘Space（D1 补丁 2）
- 用户实测：`⌥⌘Space` 同时弹出 Claude 桌面端对话窗 + Finder 搜索窗。
- 做了真实排查而不是猜：`defaults export com.apple.symbolichotkeys` 解析出当前启用的系统符号快捷键只有 8 个（`⌘Space`、`⌥⌘Space`、`⇧⌘D/F/S/Z`、`⌃X`、`⌃Z`）。`⌥⌘Space` 确实在表里 = Finder 搜索，这就是它必弹的原因。
- 结论：Space 这个键已被 AI 客户端挤爆（Gemini / ChatGPT 用 `⌥Space`，Claude 用 `⌥⌘Space`）。改用 `⌃⌥⌘Space`：不在系统符号表，AI 客户端也不用三修饰键模式。
- **快捷键改为配置文件驱动**：`~/Library/Application Support/com.sense.app/settings.json` 的 `hotkey` 字段（格式 `ctrl+alt+cmd+space`，支持 space/单字母/数字）。首启自动生成；解析失败回退默认并打印原因。
- 验证：日志 `hotkey registered: ⌃⌥⌘Space （来自 …/settings.json）`；把配置改成 `ctrl+alt+k` 重启后日志变 `⌃⌥K`，证明免重编译生效；已恢复默认。cargo test 7 passed / npm test 3 passed。
- 提交：`08edddc`(fix) + docs。
- 教训：全局快捷键不要选 Space 系；也不要假设"注册成功=没冲突"，Carbon 注册与 App 自带按键监听可以同时生效。系统符号表可以用 `defaults export com.apple.symbolichotkeys` 查，第三方 App 的默认键只能靠已知清单（Gemini/ChatGPT/Claude 都是 Space 系）。
