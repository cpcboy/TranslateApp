## 窗口放大 + 可缩放 + 字号再提一档

## 查词提速：关掉 DeepSeek thinking
- 根因：DeepSeek V4（deepseek-flash）**thinking 默认开启、effort=high**，官方文档明确。不开关，每次查词先吐几千 token 思维链。
- 关法：顶层 `{"thinking":{"type":"disabled"}}`；qwen → `enable_thinking:false`；openrouter → `reasoning:{enabled:false}`；ollama → `reasoning_effort:"none"`。集中在 `providers::reasoning_fields`。
- 400 兜底：网关不认字段时去掉重试一次，但必须「一个增量都没吐过」才行，否则内容叠两遍（review 抓到的 P1）。为此把 `ChatError::Server(String)` 拆出 `BadRequest`。
- 其它提速：启动预热 `GET /models`（drain body 才回池）、pool 60s、max_tokens 4096、前端增量 66ms 合流（原来每个 token 都重解析整包 JSON）。
- 发现的环境坑：机器设了 `HTTP_PROXY`，reqwest 会把 `127.0.0.1` 也走代理 → 本地 Ollama/LM Studio 直接不可用。加了 `client_for()`：loopback 用 `.no_proxy()` 客户端。
- 实测：mock 2000 字符 SSE → ttft 45ms / 首义项 192ms / 总计 561ms（这是我们的管线开销）。到 api.deepseek.com 的 TLS 37ms、TTFB 332ms。
- 结论：500ms 只能对缓存命中成立；新词全卡受生成速度限制（3–6s）。已写进 README「速度」与 CHANGELOG。
- 提交 3f6842c / 1127f60。
- 已知：重装后首次查词会弹钥匙串授权（cdhash 变了），用户点一次「始终允许」。

## 截屏权限「授权了还是不行」
- 根因：SENSE 是 ad-hoc 签名（`codesign -dv` → Signature=adhoc、TeamIdentifier=not set），macOS 的 TCC 记录绑二进制，重新构建后旧授权对新构建不生效，且不再弹窗。
- 修复：截屏前 `CGPreflightScreenCaptureAccess()`，没权限就 `CGRequestScreenCaptureAccess()` 弹框；失败在主窗口显示提示条；写 `capture.log`（权限/截图返回码/OCR 行数/翻译块数）；新增 `tools/grant-screen-recording.sh`（tccutil reset + 重启）。
- 注意：**沙箱内 `tccutil` 会报 Operation not permitted**，必须让用户在自己终端跑。
- 根治：代码签名证书（Apple 开发者证书或自签 Code Signing 证书），否则每次重构建都要重新授权。
